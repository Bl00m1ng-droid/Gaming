This project is a practice demo showcasing how to combine Python, Pygame, and simple graphics programming to create an interactive animation. A ball image (intro_ball.gif) bounces around the screen, changing direction when it hits the edges. Each collision triggers:

🎨 Random background color changes for visual variety

🔊 Bounce sound effects using pygame.mixer

🖼️ Smooth rendering with blit() and display.flip()

⚡ Real‑time interactivity with event handling and frame delays

The script demonstrates core game development concepts:

Initializing Pygame modules

Handling events (QUIT)

Moving sprites with velocity vectors

Collision detection with window boundaries

Adding audio feedback and dynamic visuals
